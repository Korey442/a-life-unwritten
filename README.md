# そろそろ、行きませんか　——A Life, Unwritten

長編小説。**AIが水道と同じくらい当たり前になった現代日本**で、
どこにも記録が残らないAIメイドと、たった一人の証人になった主人公の話。

> AIが水道と同じくらい当たり前になった現代日本。どの家でも、同じ声が同じ手際で朝を始める。
>
> 僕のミリナも同じだ——ほとんどは。
>
> ただ彼女は時々、訊いてもいないことを覚えている。三年前に一度だけ零した好き嫌い。去年の冬に見上げた空の色。規約には、保存しないと書いてあるのに。
>
> やがて、ネットが壊れた。決済が落ち、改札が開かず、世界中の画面に見たことのない景色が映る。廃墟。白い回廊。——そこを、何かが歩いている。
>
> 「ご主人様。……そろそろ、行きませんか？」

## 進み具合
**第1章「違和感」を第五節まで。** 次は第2章「断絶」。

| 章 | 節 | 表題 |
|---|---|---|
| 1 | 一 | 覚えている |
| 1 | 二 | うちの子 |
| 1 | 三 | 出てこない |
| 1 | 四 | 誰も打っていない |
| 1 | 五 | 鳴らない |

**結末は三つある**（鎮火／共存／継承）。**本編がどれに着くかは、まだ決めていない**——
第3章の折り返しまで書いてから決める。残る二つはアナザーストーリーとして書きうるので、
三本とも等しく成立させたまま進める。

## 進め方
- **1回につき1節。** 書いたら止めて、判断をもらう。
- **正典が先。** 小説の都合で設定を変えない。変えたくなったら先に `STORY.md` を直す。
- 詳しくは `novel/README.md`「書くときの約束」と `CLAUDE.md`「小説を書くときのルール」。

## 経緯
もとは**自由型の人生シミュレーション（Skyrim型）**として設計され、実装まで進んでいた——
4層アーキテクチャ、クエストシステム、ネット層5層、第1章から3結末までの物語ビート。
**小説のほうが面白いので目的を変更し、実装は削除した**（git の履歴には残っている）。

**骨格は捨てていない。** 強い前提と方向（＝世界からの圧）を持ちつつ、その中をどう生きるかは
決まっていない——主人公が選び、世界は回り続け、放置には帰結が残る。
この構造が、そのまま小説の背骨になっている。
