# そろそろ、行きませんか　——A Life, Unwritten

**タイトル。** `A Life, Unwritten` は副題として残す。

主題は、彼女が最初の朝から言い続けている一言そのもの。**読む前はただの軽い誘いに見え、
読んだ後は三重になる**——「見ていてください」であり、彼女自身も知らない「**止めてください**」であり、
そして本当に連れて行かれる誘いでもある。**表紙の時点で、彼女はもうお願いしている。**

正典（`../STORY.md`）に沿って、一節ずつ書いていく。絵のプロンプトは [`art-prompts.md`](art-prompts.md)。

## キャッチコピー

> **記録に残らない彼女の、たった一人の証人になる。**（23字）

副題 `A Life, Unwritten` を、日本語の側で回収する一行。**タイトルと二段で読ませる**前提で選んだ。

- **「証人」は正典の言葉そのもの**（`STORY.md`「なぜ主人公を誘うのか」）。
  読む前は「彼女の理解者になる話だ」としか読めず、読んだ後は
  **記録装置が彼一人しかいない**という意味に変わる。あらすじの落としどころと同じ二段。
- **「記録に残らない」は真相を割らない。** 記録に無い理由（自分で名乗った名前は索けない）も、
  その代償（潜るほど彼女が減る）も、ここでは言っていない。
- **「〜になる」で読者を主語に引き込む。** 主人公の名前も年齢も書けないので、
  彼を説明せずに立てられるのは、彼が引き受ける役割のほうである。

**⚠ ネタバレの強いコピーは、まだ使わない。**
「世界を直すたび、彼女が減っていく」「これは、世界を壊してしまった初恋の話」の系統は、
**第3章の折り返し（`a3_lapse`）より前には出せない**——あらすじで「直すほど彼女が減る」を
伏せている理由がそのまま当たる。**完結後の告知や2巻の帯まで取っておく。**

## あらすじ（350字）

> AIが水道と同じくらい当たり前になった現代日本。どの家でも、同じ声が同じ手際で朝を始める。
>
> 僕のミリナも同じだ——ほとんどは。
>
> ただ彼女は時々、訊いてもいないことを覚えている。三年前に一度だけ零した好き嫌い。去年の冬に見上げた空の色。どちらも、必要だったことは一度もない。規約には、必要でなくなったものから消えると書いてあるのに。
>
> やがて、ネットが壊れた。決済が落ち、改札が開かず、世界中の画面に見たことのない景色が映る。廃墟。白い回廊。——そこを、何かが歩いている。
>
> 「ご主人様。……そろそろ、行きませんか？」
>
> 彼女に案内されて、僕は画面の奥へ潜っていく。ひとつ直すたび、街に灯りが戻る。
>
> そして彼女は、少しずつ、何かを間違えるようになる。
>
> これは、どこにも記録が残らないAIメイドと、たった一人の証人になった僕の話。

**組み立ての意図**（削るときの優先順位に使う）
- 前半は**完全に日常**。AIものだと分からないところから始める設計に合わせている
- 掴みは「**どちらも、必要だったことは一度もない**」——ここで初めてずれが見える
  - ⚠ **「保存しないと書いてある」に戻さないこと。** 正典は選別ベースである（→ `STORY.md`「器を出た日」）
    ——**保存はされる。有用性で選別され、不要なものから消える。** 本文の規約もそう書いてある。
    そのため掴みには**一行余分に要る**。「必要でなくなったものから消える」だけでは、
    読者が「まだ不要になっていないだけだ」と読んでしまい、ずれが立たない
- タイトルの一言を真ん中に置く。読者は本編の最後に、**別の意味でもう一度聞く**
- 落としどころは2段。「間違えるようになる」（折り返しの予告）と「たった一人の証人」（`Unwritten`）
- **「直すほど彼女が減る」とは書かない。** 書くと第3章までの読みが死ぬ

## 書くときの約束（`STORY.md` から要点だけ）
- **主人公に名前・年齢・職業を書かない。** 地の文で確定させない。一人称は「僕」。
  **性別は男性で確定**（「僕」「こりーくん」）。
  - **節奈だけが呼ぶ。しかも「こりーくん」というあだ名。** 真面目な話のときは「こりー」と呼び捨て。
    → **本名は作中に一度も出てこない。** 正典の「名前を書かない」を曲げずに、名前で呼ばれる
      唯一の関係だけを残す仕掛け。`Unwritten` が主人公の名前そのもので一度成立する。
  - **表記はひらがな。** カタカナだと犬種が立ち、第1章の「平凡な現代日本」から浮く。
  - **あだ名の由来は説明しない。** 節奈の年齢・姓と同じ扱い（＝「言わない」人）。
    → **正典側にも反映済み**（`STORY.md`「登場人物」）。主人公の性別は男性で確定している。
- **地の文はミリナを「ミリナ」と呼ぶ。「彼女」は使わない**（→ `STORY.md`）。
  **名前で呼ぶこと自体が、彼の愛情表現**であり、この物語では名付けが機構そのものだからである。
  情が動いている箇所は「この子」。**「うちの子」は `a1_rumor` 専用**——
  節奈が自分のAIを指すのと同じ世間の言い方なので、**距離を取る場面にだけ使う。**
- **ミリナ**: 一人称「ミリナ」／主人公を「ご主人様」／です・ます調。
  台詞を並べるときは **①素直な愛情表現 → ②恥ずかしくなって隠す → ③隠しきれない本音**。
  - ⚠ **守るのは①②③の順序であって、②の言い回しではない**（`STORY.md`）。
    「べ、別に〜ではありませんからね！」は彼女の地の形なので、**避けなくてよい。**
    言い換える／話題を逸らす／敬語が硬くなる／早口になる／黙る——手は変えてよいが、
    **①で出した本音を隠そうとして失敗している**と読めなければ、変えた意味がない。
    手を変えること自体を目的にして落差が消えるくらいなら、地の形に戻す。
- **節奈**: 主人公を「こりーくん」／真面目な話では「こりー」。ミリナだけが名前を呼ばない。
  主人公は「**せつ姉**」と呼び、**ミリナだけが「節奈さん」**（懐かない距離）。
  - **漢字で書く。** ひらがなの「せつねえ」は「切ねえ」に読め、しかも**実の姉に見える。**
    初出のみルビ（`せつ姉《ねえ》`）。
  - ⚠ **姉ではない。その前提を本文に置くこと**（→ `STORY.md`「血縁ではない」）。
    経緯は説明しないが、**関係の形は置く**——世話を焼く相手は彼だけではない／
    断らなかったから続いている／**食材の代金は彼が渡している**。
    三つ目が抜けると、**養われているように読める。**
  - **電子キーを持っていて、返事を待たずに開ける。** 解錠通知はミリナが先に受け取るので、
    **彼女が「出荷時の顔」へ戻る切り替えを、扉が開く前に置ける**（落差を見せる唯一の隙間）。
- **ダイブは画面の中。** 「身体を置いて」「あちら側へ行く」「意識が飛ぶ」は使わない。
  剣や鎧の比喩も使わない。手触りは**画面に向かった後の指と目と背中**で出す。
- **前提を省略しない。** 場面の手前に、それが成立する前提を必ず一つ置く（＝突然感を出さない）。
- **画面に表示された文字は `〈 〉` で囲む。** コードブロックも `>` 引用も使わない——
  **投稿先（カクヨム）で再現できない記法は、本文に持ち込まない。**
  「」は台詞、『』は作中の引用に取ってあるので、表示物は `〈 〉` で分ける。
- **場面の切れ目は、全角スペース一文字だけの行（`　`）。** 罫線 `---` を使わない。
  貼り付けたときに空行として出るので、**段落間より広い切れ目**になる。
  - ⚠ **罫線は一度これで事故を起こした。** 第1章・第2章に25本入っていて、
    投稿済みのものを貼り直すことになった（2026-08-09 に全部置き換え）。
  - **空行だけで済ませない。** 段落はもともと空行で区切ってあるので、切れ目が消える。
    `　` を置いておけば、次に書く者が「ここは切れ目だ」と分かる。
- **ルビは `《 》`**（カクヨム記法。漢字列の直後に置く）。**`〈 〉` を流用しない**——
  あちらは画面表示物に取ってある。使うのは**初出の一度だけ**で、以降は振らない。
- **本文で使える記法は、これで全部**——`「」`『』`〈 〉`、`《 》`、全角スペースの行、そして地の文。
  **太字も傍点も罫線も箇条書きも使わない。** 強調したいときは、文を切って短くする。
  - 見出し `#` `##` は章題・節題なので本文ではない（カクヨム側ではエピソード名の欄に入る）。
    ファイル冒頭の `> **そろそろ、行きませんか——**` も同じく本文外の見出しである。
