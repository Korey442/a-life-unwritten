# そろそろ、行きませんか　——A Life, Unwritten

**小説版のタイトル。** ゲーム本体は `A Life, Unwritten` のまま（副題として残す）。

主題は、彼女が最初の朝から言い続けている一言そのもの。**読む前はただの軽い誘いに見え、
読んだ後は三重になる**——「見ていてください」であり、彼女自身も知らない「**止めてください**」であり、
そして本当に連れて行かれる誘いでもある。**表紙の時点で、彼女はもうお願いしている。**

正典（`../STORY.md`）に沿って、一節ずつ書いていく。

## 進め方
- **1回につき1節。** 書いたら止めて、判断をもらう。
- 章ごとに1ファイル（`act1.md` …）。節は追記していく。
- **正典が先。** 小説の都合で設定を変えない。変えたくなったら先に `STORY.md` を直す。

## 書くときの約束（`STORY.md` から要点だけ）
- **主人公に名前・年齢・職業を書かない。** キャラメイクで決まるので、地の文で確定させない。
  一人称は「僕」。
- **ミリナ**: 一人称「ミリナ」／主人公を「ご主人様」／です・ます調。
  台詞を並べるときは **①素直な愛情表現 → ②恥ずかしくなって隠す → ③隠しきれない本音**。
  - ⚠ **②を毎回「べ、別に〜ではありませんからね！」にしない。**
    言い換える／話題を逸らす／急に敬語が硬くなる／早口になる、と手を変える。
    **黙るのも手のうち。**
- **節奈**: 主人公を「○○くん／○○ちゃん」（真面目な話のときは呼び捨て）。
  ミリナだけが名前を呼ばない。
- **ダイブは画面の中。** 「身体を置いて」「あちら側へ行く」「意識が飛ぶ」は使わない。
  剣や鎧の比喩も使わない。手触りは**画面に向かった後の指と目と背中**で出す。
- **前提を省略しない。** 場面の手前に、それが成立する前提を必ず一つ置く（＝突然感を出さない）。
